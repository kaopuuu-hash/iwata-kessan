# 磐田市 令和7年度決算まとめ（超軽量ページ）

磐田市の令和7年度決算を、市民向けに分かりやすくまとめた単一HTMLページです。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | ページ本体。これ1つで完結（CSSは埋め込み、画像・外部通信・広告・解析なし、JSなしでも読める） |
| `README.md` | このファイル。リポジトリの説明 |
| `AGENTS.md` | AIエージェントが作業するときのルール |

## ページの内容

- 全体像：市の「3つのお財布」（一般会計／事業会計／公営企業会計）
- 数字で見る：実質収支と繰出金の内訳
- 課題：市立病院の赤字
- 借金と貯金、やさしいまとめ

数値の出典は市政報告書 第1表・第2表（数値照合表）。

## 更新のしかた

1. `index.html` を編集する（数値を変えるときは出典と照合する）
2. 変更はブランチで作業し、Pull Request 経由で `main` に入れる
3. 詳細な作業ルールは `AGENTS.md` を参照
