# 静岡市 公共施設の徒歩アクセス空白地帯 分析レポート

**テーマ：大地震発生時に「徒歩圏内の空白地帯（アクセスの悪いエリア）」をボロノイ図で可視化し、改善案を検討する**

---

## 1. 概要（サマリー）

静岡市が公開する公共施設オープンデータ（690施設）と、2020年国勢調査の500mメッシュ人口を用いて、各居住地から最寄り公共施設までの直線距離を計算し、ボロノイ（Voronoi）図で「施設の勢力圏」を可視化した。さらに、施設までの距離が**1kmを超える居住域**を「徒歩アクセスの空白地帯」として抽出し、改善優先候補地を貪欲法で算出した。

| 指標 | 値 |
|---|---|
| 対象施設数 | 658地点（690件から重複・市外・座標異常を除外） |
| 推計居住人口（500mメッシュ，市域内） | 約 675,500 人 |
| 徒歩500m以内に施設がある人口 | 476,300人（**70.5%**） |
| 徒歩1km超でしか施設に届かない人口 | 21,897人（**3.2%**） |
| 徒歩空白メッシュ（1km超）の数 | **447メッシュ** |
| 空白地帯の最多は葵区（9,777人）・清水区（8,830人） |

**結論：** 市街地（葵区南部・駿河区・清水区市街）はほぼ100%カバーされているが、**葵区北部・梅ヶ島・井川・玉川など中山間部と、清水区の山間・湾岸端部**に明確な徒歩空白が集中している。市域全体では「1km圏外」は3.2%にとどまるが、これは平地への人口集中の裏返しであり、**空白地帯に住む人の多くは高齢者**で、地震時の徒歩避難リスクが高い。

## 2. データと方法

### 2.1 使用データ（すべてオープンデータ）

| データ | 出典 | ライセンス |
|---|---|---|
| 静岡市が保有する公共施設情報一覧（690件，緯度経度付きCSV） | 静岡県オープンデータ（県庁サイト）／2026-09-09更新 | CC BY（表示） |
| 行政区域（市町村界）ポリゴン | 国土数値情報 N03（2023年版） | 国交省 オープンデータ |
| 500mメッシュ人口・世帯（2020年国勢調査） | e-Stat 統計GIS を再配布する Parquet | CC BY 4.0 |

### 2.2 手順

1. **座標系**：地理座標（JGD2011, EPSG:6668）から **UTM第54帯（EPSG:6692）** に投影し、メートル単位で実距離を計算。
2. **施設点の整理**：市域外・誤座標（例：住所は葵区だが緯度が富士市相当）を除去し、同一座標の棟単位重複を間引き、658代表点に。
3. **ボロノイ図**：658施設を母点とするボロノイ分割を作成し、市域ポリゴンでクリップ。各セルが「その施設が最寄りとなる範囲」を示す。
4. **徒歩圏カバレッジ**：各500mメッシュ中心から最寄り施設までの距離を計算。境界メッシュは市域内面積比で人口を按分した。
   - ≤500m：良好（徒歩6〜7分相当）
   - 500m〜1km：やや遠い（徒歩10〜13分相当）
   - ＞1km：**空白（徒歩15分超／地震時に徒歩避難が困難）**
5. **空白地帯の抽出と改善候補地の算出**：1km圏外の人口を最も多く減らせる地点を貪欲法で8か所選定。

### 2.3 注意（前提と限界）

- 距離は**直線距離**。実際の道路・急傾斜・河川・国道の横断可否は考慮していない。中山間部では実歩行距離はさらに長くなる。
- 人口メッシュは市域にかかるものを採用し、境界メッシュは**市域内面積比で人口を按分**している。
- 施設は「アセットマネジメント対象の公共建築物」。避難所指定の有無・耐震性・液状化・津波浸水は別途の考慮が必要。
- 「公共施設がある＝地震時に使える」ではない。本分析は**平常時の施設分布を徒歩距離の代理指標**として用いている。

## 4. 考察：なぜこの空白が地震時に問題か

1. **中山間部の孤立集落**：井川・梅ヶ島・玉川・大河内などは、そもそも公共施設まで数km。地震で林道・県道が寸断されると、徒歩での避難・物資到達が事実上不可能になる（ボロノイ区画の巨大さがそのまま「孤立リスク」）。
2. **市街地外縁の見落とし**：北五丁目・足久保・梅ヶ谷などは「市街地の一部」に見えるが、最寄り公共施設まで1km超。ここは高齢化率も高く、**要援護者の徒歩避難先がない**。
3. **施設定数と配置の偏り**：658施設のほとんどが市街地（清水港周辺〜静岡駅南部）に集中。市域面積の大半を占める葵区北部には、温泉施設や山小屋など「避難所にならない施設」が点在するにとどまる。
4. **500m圏でも29.5%が圏外**：地震直後の「徒歩で安全な場所まで行けるか」という観点では、3割の住民が500m圏外にいる。中でも中山間・郊外外縁は300m以上の高低差や急傾斜を含むため、実効的な徒歩時間はさらに延びる。

## 5. 改善案

### 5.1 優先配置候補地（1kmカバーを最大化）

1km圏外の人口を最も多く減らせる地点を貪欲法で算出した結果（★は `final_urban.png` に描画）。既存施設の空白を埋める**新設または協定避難所指定**の候補地として有効。

| 優先 | 座標 | 追加被覆人口 | 想定エリア |
|---|---|---|---|
| 1 | 35.03542, 138.40313 | **+2,466人** | 葵区 北五丁目周辺 |
| 2 | 35.06875, 138.47188 | +1,506人 | 清水区 中河内・杉山方面 |
| 3 | 35.04792, 138.43437 | +1,356人 | 清水区 梅ヶ谷・山切 |
| 4 | 34.95625, 138.43437 | +1,334人 | 駿河区 大谷周辺 |
| 5 | 34.93958, 138.32812 | +994人 | 駿河区 丸子 |
| 6 | 35.04792, 138.35312 | +963人 | 葵区 足久保 |
| 7 | 35.07292, 138.52187 | +822人 | 清水区 谷津町・興津 |
| 8 | 34.98958, 138.29062 | +630人 | 葵区 谷津・西部山間 |

- これら8地点を追加すると、**1km圏の人口カバー率が 96.8% → 98.2%** に改善（約1万人の圏外人口を削減）。
- すべて**既存の公共公益施設（学校・公民館・集会所・郵便局等）への機能付加**で対応可能なエリアであり、新規建築を最小化できる。

### 5.2 空白地帯の機能強化策

1. **指定避難所の「徒歩空白」補完**
   - 空白メッシュ内の既存集会所・自治会館・寺社・公園を「一時避難場所」として順次指定。
   - 特に北五丁目・梅ヶ谷・足久保・大谷には、近隣の学校区をまたぐ避難協定を検討。

2. **中山間部の「孤立集落」対策（物理的到達の担保）**
   - 井川・梅ヶ島・玉川・大河内について、ボロノイ区画が広い施設を**地域防災拠点（ヘリポート・備蓄庫併設）**に格上げ。
   - 道路寸断を前提に、**物資の空中投下・ヘリ輸送の目標地点**として座標を登録。

3. **徒歩避難の現実性を踏まえた運用**
   - 直線1kmは平地で徒歩15分だが、中山間では傾斜補正で20〜30分。**距離ではなく「所要時間」基準**に置き換えた再評価を推奨。
   - 高齢単身世帯（1km圏外に約1,200世帯）に対し、**個別避難計画（マイ・タイムライン）**を作成し、徒歩圏外であることを明示。

4. **データの継続更新**
   - 本分析を毎年更新し、施設の新設・統廃合、人口動態の変化をモニタリング。
   - 直線距離に加え、**道路ネットワーク距離（徒歩ルート）**による `network Voronoi` へ発展させることが望ましい。

### 5.3 検討の優先順位

1. **葵区北五丁目**（人口1,118・単身高齢165）＝徒歩空白最大。最優先で避難先確保。
2. **清水区 梅ヶ谷〜谷津町、駿河区 大谷〜丸子**＝市街地外縁の高齢集住。次点で整備。
3. **葵区・清水区の中山間集落**＝面的な空白。ヘリ・備蓄拠点としての整備。
